# TaskFlow - JavaScript Logic & State Management

## Project Overview

TaskFlow is a client-side To-Do List application built using:

- HTML
- CSS
- Vanilla JavaScript
- DOM manipulation
- Event handling
- localStorage

The application demonstrates complete CRUD functionality and state management.

---

## Main Requirements Covered

### 1. Create

Users can create new tasks by entering a task title and selecting:

- Priority
- Due date

### 2. Read

Tasks are loaded automatically from browser localStorage when the application starts.

### 3. Update

Users can:

- Edit task titles
- Change completion status

### 4. Delete

Users can:

- Delete individual tasks
- Clear completed tasks
- Delete all tasks

---

## Additional Features

The application also includes:

- All / Active / Completed filters
- Search
- Task sorting
- Priority levels
- Due dates
- Overdue task detection
- Task statistics
- Completion percentage
- Dark/light theme
- Responsive design
- Toast notifications
- Browser reload persistence
- Keyboard support for editing
